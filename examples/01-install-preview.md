# 示例 01 · 安装前的 dry-run 预览

这是用户选择「OKR 系统安装」后,Agent 在**写入任何文件之前**展示的预览。
脱敏自一次真实运行(`--graph <你的 Logseq 图谱> --year 2026 --quarter 3 --month 7 --week 27`)。

---

我是 OKR Doing Agent。

我会先帮你在 Logseq 里安装一套十年尺度的轻量 OKR 系统:
Dashboard、十年计划、年度 OKR、Q1-Q4、1-12 月、当前周入口,以及十年计划/年度 OKR/项目/大事件/daily routine/周复盘可调用模板。

我不会直接覆盖你的内容。写入前会先给你看预览。

```text
模式:dry-run
目标工具:Logseq
十年计划:十年计划(2021-2030)
是否写入文件:否
是否可直接写入:是
```

**将创建/检测这些系统页面:**

- `OKR Dashboard` —— 总入口:当前十年、年度、季度/月度、本周入口
- `OKR Templates` —— 模板库:承载 Logseq `template::` 块
- `十年计划(2021-2030)` —— 长期愿景、年度年鉴、跨年复盘
- `2026 OKRs` —— 年度判断:方向、项目索引、Bayesian Update
- `2026Q1` … `2026Q4` —— 季度索引
- `2026 1月` … `2026 12月` —— 月度执行
- `2026-W27` —— 当前周入口:本周 3 Things、证据、周复盘

**将安装这些可调用模板:** 十年计划 / 年度 OKR / 项目 OKR / 大事件 / daily routine / 周复盘。

**不会默认创建,后续按需生成:** `Project/<项目名>`、`大事件/<事件名>`、后续周页 —— 避免一次生成 52 个空页面。

**安全检查:**

- ✅ 未发现同名系统页面冲突
- ✅ 模板来自内置模板包,不由 Agent 临场编写

---

> 确认后才会写入。安装完成后才会问:
> **「系统已经装好了。现在要不要把一件想做的事接进来?」**
